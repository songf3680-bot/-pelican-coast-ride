# 鹈鹕海岸骑行

骑着单车沿海岸前进，收集小鱼并跳过沙堡。骑行结束后，浏览器会保存最佳里程。

## 运行

需要 Python 3（本地预览）和 Node.js 22 或更新版本（自动测试）。游戏无需安装依赖。

在此目录运行 `npm run dev`，再打开 <http://localhost:3000>。

- **刹车和加速**：在地面点一下刹车或加速按钮，或轻按 ← / →（也可用 A / D），车速就降低或提高 3 米/秒，直到最低 14.4 或最高 23.6 米/秒。仪表盘显示当前车速，起步为 17.2 米/秒。松开后保持当前速度，长按只调一次。空中保持起跳时的车速，落地后可再次调速。
- **跳跃**：点击或轻触游戏画面，也可以按空格、方向键 ↑ 或 W。
- **暂停和继续**：P 或 Esc。
- **触屏**：点按画面下方的刹车、加速或跳跃按钮。

## 自动测试

运行 `npm test` 执行一轮测试。开发时运行 `npm run test:watch`，它会在启动时测试，并在游戏源码或测试文件保存后自动再跑一轮。测试覆盖骑行状态、鱼和沙堡的碰撞、最佳里程、低速越障、车轮和踏板联动以及背景视差。
